# Predator-Prey-with-Human-Intervention
The R code for the project I worked on for a Graduate Seminar during my Master's. The project was to investigate how human hunting can interfere with predator prey systems. We used both an ODE predator-prey system and a stochastic version involving a continuous multivariate birth death process. We estimated parameters using data from isle royale, 
and we investigated how varying hunting quotas affected equilibrium points of the ODE system. We also investigated how varying hunting quotas impacts extinction probabilities in the stochastic model. Then we compared and contrasted the results. We found the predators had a signifincant chance in the stochastic model to go extinct at hunting levels where the ODE model predicted they would survive.

Note that I didn't include the results we computed while working on the project or the technical report.
